# Household Chore Rotation Tool — Scope

## Users

- Couple / roommates sharing a household
- Shared web app — everyone accesses the same view from their own phone/laptop
- Data is stored centrally (shared storage) so all users see the same state in real time

## Chores

- Selected from a **preset chore list**
- Only **daily** and **weekly** chores are tracked (no monthly/rare deep-clean tasks)
- Setup is minimal: pick from the preset list, then add household members' names

## Assignment

- **Fixed rotation** per chore (predictable, no daily negotiating)
- **Manual swap** allowed between two people when someone needs to trade a turn
- No random assignment, no points/fairness system, no free-claim list

## Completion Tracking

- Simple **checkbox** to mark a chore done
- Records **who completed it**
- Builds a **history log** over time (who did what, when)

## Overdue Handling

- Missed chores trigger an **in-app visual reminder/nudge**
- Note: since this runs as a browser-based tool, there are no true push notifications — reminders only show while the app is open

## Out of Scope (for now)

- Monthly/rare/deep-clean chores
- Points or fairness-balancing systems
- Random/shuffled assignment
- Photo-proof verification
- Push notifications outside the browser
- Single shared wall-mounted screen (using personal devices instead)
